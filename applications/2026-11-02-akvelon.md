## Interview prep

- **"Walk us through an agent harness you built."** The Shopping Assistant graph:
  - tools (search, memory write);
  - state in the Postgres checkpointer;
  - typed facts for long-term memory (not vector memory);
  - bounded retries;
  - input and memory-write guardrails (0 of 21 legitimate facts refused).
  Then the evaluation loop: 12 tasks × 3 runs, Langfuse traces, and a v2/v3 change log with numbers.
- **"How do you configure Claude Code for a project?"**
  - A CLAUDE.md with the rules and workflow, including truthfulness rules and build commands.
  - A SessionStart hook that installs dependencies.
  - Tests and builds you run after every change.
  - Reviewing every diff it writes.
- **"MCP?"** Be honest that you haven't built an MCP server yet. You know it's the standard way to expose tools to agents, and you could wrap the Shopping Assistant's search tool as one. Building one before the interview would help (see below).
- **"Cloud?"** No production cloud work yet: Docker, GitHub Actions and Hugging Face Spaces. Mention your AWS Cloud Practitioner sessions only if you've actually started them.
- **"Agent governance?"** Guardrails on what the agent may write to memory, a cap of 50 stored facts per user, bounded retries, and traces of every tool call. Human-in-the-loop approval is the next step you'd add.
- **Ask them:** which clients and projects the AI team works on, how they split agent work between Claude Code and Codex, and the usual hours of overlap with the US.
