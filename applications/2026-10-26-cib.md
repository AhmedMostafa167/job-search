## Interview prep

- **LLMOps end to end:**
  - Versioning prompts (Langfuse) and data (DVC).
  - Running evaluations in CI before a release (your 12-task × 3-run test).
  - Monitoring latency, errors and cost in production (Prometheus/Grafana).
  - Rolling back a bad prompt.
- **Drift (gap):** know the types: data drift (inputs change), concept drift (the right answer changes), and for LLM apps, prompt and model-version drift. Tools: population stability index (PSI) and KL divergence on features, tracking evaluation scores over time, alerting on retrieval-recall drops.
- **RAG in a bank:** access control on documents, grounding answers in sources (your `prices_grounded` check), PII masking, audit logs, and saying "I don't know".
- **API design:** FastAPI, Pydantic schemas, timeouts and retries, rate limits, auth, versioned endpoints.
- **Kubernetes (gap):** know pods, deployments, services, scaling, and how a Docker Compose setup maps to Kubernetes.
- **Testing:** unit vs integration tests for LLM code. Mock the model, then run evaluation tests on real calls.
