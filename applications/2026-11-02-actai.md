I build the layer your LLM Application Engineer role describes: agent workflows that turn probabilistic model output into reliable behaviour, measured with evaluation sets. On my shopping assistant (LangGraph, tool calling, long-term memory, hybrid retrieval with reranking), a 12-task suite with 3 runs each drove a prompt rewrite from 7 to 12 of 12 tasks with 29% fewer paid rerank calls, reranking moved the right product to first place from 23% to 43%, and an HNSW index cut median search latency from 35 ms to 3.1 ms. ## Interview prep

- **Design question.** "Make an agent reliably schedule a meeting from a chat thread." Walk through:
  - structured extraction;
  - a tool call;
  - validating the call;
  - a bounded retry;
  - an evaluation set of messy threads.
- **"How do you catch regressions?"** Fixed task suites, several runs per task, pass rates and paid-call counts compared across prompt versions in Langfuse and MLflow.
- **Retrieval question.** Why hybrid beats vector-only on product names and numbers, how Reciprocal Rank Fusion works, and when reranking is worth its cost.
