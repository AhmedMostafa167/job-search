## Interview prep

- **Prototype thinking:** they build prototypes and MVPs in 1–4 weeks, so expect "how would you build X in a week?" Answer with the smallest working slice first, an evaluation set from day one, then iterate.
- **RAG:** chunking, embedding choice, hybrid search vs vector-only (your 72/56/41), reranking (23% → 43%), and evaluating retrieval with recall@k.
- **APIs:** a FastAPI endpoint for an LLM feature: request and response schemas with Pydantic, streaming, timeouts and retries, Docker packaging.
- **Model comparison (their R&D service):** comparing models on the same task set for quality, latency and cost. Your prompt v1 vs v2 test is a small example.
- **Fine-tuning and small models:** your LoRA work on Stable Diffusion; know when fine-tuning beats prompting or RAG.
- **Questions to ask them:** the internship location or remote setup, the monthly stipend, the hours and time zone, and how the full-time decision is made.
