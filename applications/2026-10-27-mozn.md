## Interview prep

- **Fraud and AML basics:** class imbalance (fraud is rare), so precision/recall and PR-AUC rather than accuracy; cost of false positives (alert fatigue) vs false negatives; features like transaction velocity, amounts vs customer history, device and location changes.
- **GenAI use cases they named:** document analysis, alert summarisation and data enrichment. Explain how you'd build an alert summariser with RAG, how you'd evaluate it (a labelled set, grounding checks like your `prices_grounded` check), and how you'd stop hallucinated facts.
- **SQL:** joins, GROUP BY, window functions (e.g., each customer's last 5 transactions).
- **Ask them:** which product the role supports (fraud, AML or knowledge intelligence), and mentorship for juniors.
