## Original post

> Associate Software Testing Engineer — AIC (MCIT), Cairo, Full-Time, Associate, Software Development. Job Code: SW001.
> The Applied Innovation Center (AIC) of MCIT is looking for Associate Software Testing Engineer to produce scalable Hi-Tec software solutions. As Associate Software Testing Engineer, you should be comfortable around both front-end and back-end coding languages, development frameworks and third-party libraries. You should also be a team player with a knack for visual design and utility.
> Responsibilities:
> - Running Tests: Following step-by-step scripts (manual and automated) to check if the software works correctly and documenting the results.
> - Managing Bugs: Identifying software errors and writing detailed reports for developers explaining how to find and fix the problems, then retesting fixes.
> - Preparing Data: Setting up environments and mock user accounts needed for specific test scenarios.
> - Documentation: Maintaining clear, structured test plans, bug reports, and regression logs.
> - CI/CD: Integrating automated tests into the CI pipeline for faster feedback.
> - User Experience Validation: Ensuring usability and accessibility standards are met.
> Qualifications:
> - Bachelor BSc. of Computer Engineering/Science.
> - Minimum two years of experience in software testing.
