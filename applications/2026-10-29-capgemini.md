## Interview prep

- **Copilot Studio / Power Platform (gap):** read Microsoft's Copilot Studio overview (topics, generative answers, actions/connectors) and Power Automate flows before the interview. Be able to map your LangGraph agent onto those ideas: tool calling ≈ actions/connectors, state ≈ variables, RAG ≈ generative answers over knowledge sources.
- **Integrations:** REST, JSON, authentication (API keys, OAuth basics), webhooks vs polling, retries, idempotency.
- **ALM / environments:** DEV → QA → UAT → Prod, environment variables, secrets, and how your GitHub Actions CI gates a change.
- **Testing (both roles):** unit vs integration tests in your 104 pytest tests, how you test non-deterministic LLM output (code-graded checks, fixed tasks × 3 runs), and the `prices_grounded` check (25 of 25 runs).
- **L3 support:** walk through debugging a failed tool call or a bad retrieval using Langfuse traces and Prometheus/Grafana.
- **Ask them:** which clients the Cairo hub serves, and how much of the work is Power Platform vs Python.
